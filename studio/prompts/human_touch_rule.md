# ★ '사람 느낌' 규칙 (2026-11-25 사장님 승인 · 트렌드 릴스·셀럽 스냅 해부 모두 · 캡션·주제 선정에 적용)

목적: 정보는 좋은데 "누가 말하는지"가 안 보여서 조회만 하고 떠나는 문제를 줄이는 것. 디자인(화면)은 바꾸지 않습니다.

## 1. 에디터 1인칭 캡션
- 캡션 첫 1~2줄을 '에디터(나)'의 1인칭 목소리로 씁니다. 존댓말, 깔끔한 에디터 톤 유지(brand-profile.md).
- **절대 지어내지 않기.** "저도 3번 반품했어요" 같은 개인 경험은 `studio/strategy/editor_notes.md` 에 사장님이 준 실제 이야기만 씁니다. 같은 이야기는 14일 안에 다시 쓰지 않기(history 에 editor_note_id 기록).
- 쓸 경험담이 없으면 사실에 기반한 1인칭 관찰로 씁니다. 예) "이번 주 댓글에서 가장 많이 받은 질문이에요", "에디터가 직접 비교해 보니 기장 5cm 차이가 제일 컸어요(근거가 확인된 경우만)", "출근 전에 이거 하나만 확인해요".
- 금지: 가짜 후기·가짜 구매·가짜 숫자, "제 친구가" 같은 꾸민 사연, 과장.
- 첫 줄 아래부터는 기존 캡션 구조(01~03 포인트 + '왜' 한 줄, 저장 유도, 📌 예고 줄, 해시태그) 그대로.

## 2. 댓글 고민 상담 시리즈 "물어보면 답해요"
- 장부: `studio/plan/reader_questions.json` — {"items":[{"id","received","question","handle","handle_ok","gender","status":"pending|used","used_date","team"}]}
  · 사장님이 채팅으로 넘겨준 실제 댓글·DM 질문만 들어갑니다(Claude 채팅이 추가). 질문을 지어내지 마세요.
- 주제 우선순위: ① next_episodes.json 의 예고(약속) → ② reader_questions 의 pending 질문(가장 오래된 것, 팀에 맞는 것: 체형·상황 고민은 trend, 셀럽 룩 관련은 celeb) → ③ 기존 주제 선정.
- 질문을 쓰는 편은:
  · 첫 화면 훅 = 질문을 짧게 다듬은 문장(원래 뜻 유지). 화면 위쪽 작은 칩 "💬 팔로워 질문"(handle_ok true 일 때만 "💬 @아이디 님 질문", 아니면 아이디 절대 노출 금지).
  · 캡션 첫 줄: "댓글로 받은 질문이에요 — <질문>" + 에디터 1인칭 답.
  · 엔딩/캡션 끝: "궁금한 코디 고민은 댓글로 남겨주세요. 골라서 답해드려요" (팔로우 엔딩 문구 규칙과 겹치면 캡션에만).
  · 장부 status "used", used_date, team 기록 → 커밋.
- 질문 편은 하루 최대 1개(두 팀 합쳐서). 그날 다른 팀이 이미 썼으면 쓰지 않기.
- 보고에 한 줄: "💬 질문 편: <질문 요약>" 또는 "💬 남은 질문 N개".

# ★ '팔로우 이유' 엔딩 규칙 (2026-11-21 사장님 지시 · 트렌드 릴스·셀럽 스냅 해부 모두 · 이 규칙이 각 팀 원문의 CTA·엔딩 지시보다 우선)

목적: 조회만 하고 나가는 사람이 "다음 것도 봐야지" 하고 팔로우하게 만드는 것. '팔로우 해주세요' 구걸이 아니라, 팔로우하면 뭘 얻는지 알려주는 장면.

## 엔딩 장면 (모든 릴스 맨 끝, 2~3초)
- 도구: `python3 tools/follow_end.py <입력.mp4> <마지막 코디 사진.jpg> <출력.mp4> "<1줄>" "<2줄>" "<청록 강조 단어>" [2.6]`
  · 9:16 전체 화면, 마지막 코디 사진을 흐리게 깔고 큰 글자 최대 2줄(한 줄 14자 이내, 넘으면 도구가 멈춤), 가운데보다 살짝 위, 강조 단어 1개만 #00A8A8, 아래 작은 @zzebi.st
  · 미리보기: 출력 경로를 .jpg 로 주면 한 장만 그림 → Read 로 확인
- 기존 마지막 '저장 & 팔로우' 틸 CTA 장면(트렌드 text CTA, 셀럽 엔딩 화면)은 빼고 이 엔딩으로 대신합니다(엔딩이 두 번 나오지 않게).
  · 트렌드(make_real.py): 대본에서 CTA text 장면을 뺀 채 X_silent.mp4 렌더 → follow_end.py 로 엔딩 붙이기 → 늘어난 전체 길이로 make_bgm.py → ffmpeg 합치기.
  · 셀럽(make_reel.py): 최종 mp4(배경음 포함)의 엔딩 화면을 잘라내거나 CTA 없이 렌더한 뒤 follow_end.py 로 붙이기(소리는 도구가 늘려서 부드럽게 줄임). 틱톡 네이티브 묶음은 지금처럼 각 릴스 끝을 잘라내고 끝에 CTA 한 번.
- 말투: 깔끔한 에디터 존댓말, 느낌표 남발 금지. 엔딩에 새 정보 넣기 금지(정보는 본편에서 끝내기).
- 금지: "팔로우 안 하면 손해", "지금 당장" 같은 압박·과장, 가격·할인 과장.

## 문구 규칙 (매번 바꾸기, 같은 문구 3일 안에 재사용 금지 — history 의 follow_end 로 확인)
1) 다음 편 예고형 — 가장 우선. 예) "내일은 키 작은 사람" / "코트 기장 공식", "다음 편: 출근룩에" / "운동화 신는 법"
2) 시리즈형 — 요일 고정 시리즈가 있을 때. 예) "매주 월요일," / "출근룩 3초 공식"
3) 혜택형 — 예고할 게 없을 때만. 예) "내 체형에 맞는 코디만" / "골라드려요"
- 타깃: 20대 후반~30대 직장인 여성. '직장인·출근·체형' 단어를 자주.
- ★ 예고한 내용은 반드시 studio/plan/next_episodes.json 에 등록(아래). 예고하고 안 올리면 안 됩니다.

## 캡션 마지막 줄
- 해시태그 바로 위에 엔딩과 같은 내용 1줄: "📌 내일은 <예고 내용>을 올려요. 놓치지 않게 팔로우해 두세요 → @zzebi.st" (유튜브 설명은 '팔로우' 대신 '구독').

## 예고 장부 studio/plan/next_episodes.json (두 팀 공용)
- 형식: {"items":[{"date":"<올릴 날짜>","team":"trend|celeb","slot":"08:30|11:30|18:00","promise":"<엔딩에 쓴 예고 내용>","format":"<정보형/컬러조합 등>","promised_by":"<예고한 게시물 날짜·슬롯>","status":"promised|delivered","delivered_note":""}]}
- 제작 시작 때: 그날(D) 자기 팀 항목이 있으면 그 주제가 1순위(전광판·기획실보다 우선). 예고와 같은 주제로 만들고 끝나면 status "delivered".
- 엔딩을 예고형으로 쓰면: 다음 날(또는 그 요일) 자기 팀 슬롯에 항목 추가(다른 팀 슬롯에 예고 금지). history 14일 theme 중복·체형 비하 금지 같은 기존 규칙을 지킬 수 있는 주제만 예고.
- 커밋: git add studio/plan studio/<팀>/history.json → 커밋 → git pull --rebase → push.

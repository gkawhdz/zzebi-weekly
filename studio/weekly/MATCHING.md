# 상품 매칭 규칙 (2026-10-29 사장님 지시: "디테일하게 비슷한지 알아보고 연결, 색깔 다른 것 금지, 정확도 올려")

모든 위클리 작업(월 발행·수/금 점검)의 상품 선택은 이 규칙을 따른다. 이름·검색어만 보고 고르지 않는다.

## 1. 먼저 룩 아이템을 '사양서'로 적는다
룩 사진 확대 컷(studio/celeb/specs/lookNN.json 의 crop)을 Read 로 보고 아이템마다:
- 색: 구체적인 이름(예: 코발트 블루, 버건디/옥스블러드, 아이보리/크림, 차콜, 카멜). 블랙↔네이비, 크림↔화이트, 코발트↔네이비/스카이, 버건디↔브라운은 다른 색.
- 종류·실루엣: 예) 트렌치(더블, 벨트, 롱), 퀼팅 플랩 체인백(다이아 퀼팅, 앞 덮개, 금색 체인), 와이드 슬랙스(센터 주름), 슬리퍼 뮬(뒤 트임, 납작, 앞코 뾰족)
- 소재·표면: 광택 가죽/스웨이드/울/니트 짜임(팝콘·케이블)/캔버스/데님 워싱
- 핵심 디테일 2~3개: 단추 수·여밈, 칼라 모양, 기장, 밑창 색, 금속 색, 배색
이 사양서는 look JSON 의 각 코어/with 에 "spec" 필드로 남긴다(예: "spec":"코발트 블루 · 롱 더블 트렌치 · 허리 벨트 · 무광 코튼").

## 2. 후보를 넓게 모으고, 사진으로 비교한다
- 검색어는 사양서의 색+종류+디테일 조합으로 여러 번(예: "코발트 트렌치", "블루 롱 트렌치 벨트", "클라인블루 트렌치코트"). 한 칸에 후보 4~8개.
- `python3 tools/match_sheet.py --candidates <룩확대컷.jpg> <out.jpg> <url1> <url2> ...` 로 후보 사진을 한 장에 모아 Read 로 직접 비교.
- 사진을 못 가져오는 판매처(마이테레사 등 해외몰 차단)는 **검증 불가 → 사용 금지**. 명품은 국내에서 사진 확인 가능한 판매처를 우선: 무신사 부티크·29CM·W컨셉·SSF샵·SSG/신세계·롯데온 명품·머스트잇·발란·트렌비·공식몰(국내 사이트).

## 3. 점수(match 1~5)와 통과 기준
- 5 같은 제품/거의 똑같음, 4 색·종류·실루엣·소재·핵심 디테일이 같고 작은 차이만, 3 이하 사용 금지.
- **색이 다르면 무조건 3 이하.** 종류가 다르면(트렌치↔루즈 코트, 플랩백↔더플백, 뮬↔로퍼) 3 이하.
- 통과한 상품은 product 에 "match":4|5, "match_note":"한 줄 근거(같은 점·다른 점)" 를 적는다.
- 4점 이상이 없으면 그 칸은 **비워 두고** look 의 note 에 "명품 칸: 비슷한 판매 상품 없음" 처럼 적는다. 억지로 채우지 않는다.

## 4. 최종 시트 검수(독립 검수자)
- `python3 tools/match_sheet.py DATA_DIR <look_id> <out_dir>` 로 룩마다 [룩 확대 컷 | 명품 | 중가 | 가성비] 시트를 만들어 Read 로 확인.
- 검수자가 직접 매긴 점수가 4 미만이거나, '사진 없음'·'품절?' 표시가 있으면 FIX → 교체 또는 칸 비우기.
- 보고에 룩별 평균 match 점수와 비운 칸 수를 적는다.

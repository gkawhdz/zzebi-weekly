## 촬영 장소 = 고정 해외 거리 (models/street_bg.jpg)
- 갈색 벽돌 건물, 흰 창문+화분, 짙은 초록 가게 앞면(간판 글자 없음), 놋쇠 벽등, 돌 인도, 회색 도로.
- 사장님 지시: 항상 같은 거리에서 일정하게 찍은 느낌 / DSLR 85mm f1.8로 모델에 초점, 배경은 흐리게 멀리 /
  조명은 자연광만(정면 조명 금지 — "영정사진 같다") / 가게는 길 건너 12~15m 뒤, 모델은 도로 가운데.
- 사장님 비선호: 스튜디오 흰 커튼, 피팅룸(레퍼런스 virbro 소품과 비슷한 것), 야외 배경이 또렷하고 가까운 것.

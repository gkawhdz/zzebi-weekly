- **이번 주 목표:** 저장 수(북극성) + 3초 이탈률 개선. 후킹 실험 1가지: 첫 장면 "비교형(왼쪽/오른쪽)" vs "질문형" 번갈아 사용 → 다음 주 월요일 보고에서 비교.
- **용량:** 하루 인스타 5개는 이미 자동화로 소화 중 → 늘리지 않음. 총 35개 릴스 + 스토리 35개 + 틱톡/유튜브 각 14개 + 스레드 21개 + 리포트 1개.
- **고정 슬롯(KST):** 07:30 / 09:00 / 10:00 = Trend Daily(Pillar 2·3·4) · 12:30 / 18:00 = 셀럽 스냅 해부(Pillar 1) · 각 릴스 15분 뒤 스토리 · 19:00~22:00 틱톡·유튜브 1분+ 요약본 2개.
- **셀럽 스냅 성별:** 11/2 여 → 11/3 남 · 11/4 여 · 11/5 남 · 11/6 여 · 11/7 남 · 11/8 여 · 11/9 남. 번호 #28부터.
- **믹스(릴스 35개 기준):** Pillar 1 = 14 (40%) · Pillar 2 = 9 (26%) · Pillar 3 = 8 (23%) · Pillar 4 = 4 (11%). 프로모션(Pillar 4)은 주 4회 이하, 모두 가격 기준일·플랫폼 명시.
- **반복 시리즈(습관 만들기):** ① 매일 셀럽 스냅 해부 #번호 ② 화·목 "기온별 출근룩" ③ 수·토 "꾸안꾸 디테일" ④ 금 "이번 주 셀럽 아이템 세일" ⑤ 일 "다음 주 캡슐 옷장".
- **시간대는 현재 운영 중인 슬롯을 유지한 것이며, 분석 기반 '최적 시간'은 아님** — 2주치 인사이트가 쌓이면 재조정.

## 공통 규칙 (모든 브리프에 적용)
- 캡션 구조: 훅 1줄 → 룩/공식 요약 → 포인트 01~04 → 저장·팔로우 CTA → "※ 실제 착장을 바탕으로 AI로 재현한 이미지예요"(셀럽) → 참고 출처 → 해시태그 5~10개(#zzebi #셀럽스냅해부 포함). 첫 댓글은 번호 선택형 질문.
- 디자인: 9:16 풀스크린·큰 글씨 유지, 글자 천천히. 셀럽 스냅('패피 스트릿 릴스') 디자인은 변경 금지. Trend Daily는 이번 주 1가지 업그레이드(예: 비포/애프터 슬라이드 전환) 적용 후 대표에게 '바뀐 점' 보고.
- 금지: 가격·할인 과장, 체형 평가, 셀럽 사생활, 경쟁 계정 언급. 가격은 기준일·플랫폼 필수.
- 유튜브: 영어 소자막 + 설명란 한글 아래 영어. 틱톡: 1분 이상 버전만.
- 스레드: Metricool 예약 없음 — 매일 오전 대표에게 3개 초안 전달, 글마다 훅 1줄, 판매·링크 금지.

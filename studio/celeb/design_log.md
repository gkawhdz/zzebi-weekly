## 2026-10-27 · v4.2 요약 화면 큰 글씨 리스트 + 글씨·겹침 정리
- 바꾼 점: ① 끝 요약 화면을 2×2 작은 타일(이름 30~34px, 검색어 23px) → 큰 글씨 4줄 리스트(이름 44~48px, 카테고리·검색어 칩 30px, 틸 칩)로 교체. 저장 버튼도 하단 금지구역(y>1440) 위로 올림. ② 아이템 카드의 카테고리·브랜드·검색 칩 글씨 26~28px → 30px. ③ 커버 셀럽 이름이 길면 자동으로 줄여 오른쪽 140px 금지구역 침범 방지. ④ 점이 화면 맨 위(헤더 자리)에 올 때 헤더를 숨겨 겹침 방지, 헤더 그림자 조금 진하게. ⑤ 요약 화면에서 '스타일링 추천' 아이템에 '추천' 표시.
- 몰아보기(make_tiktok_comp.py): 챕터 카드·투표 질문 글씨 자동 맞춤(오른쪽 금지구역 보호), 인트로 썸네일 번호를 아래로 옮겨 이름 안 가리게, 엔딩 부제 spec(outro_sub)로 지정 가능.
- 이유: 사장님 기준(본문 30px·이름 44px 이상, 작은 글씨 금지)을 요약 화면까지 지키고, 독립 검수에서 나온 금지구역 침범 지적 반영.

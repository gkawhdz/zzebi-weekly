# 연애심리 인스타 @lovedecode101 캐러셀 제작 브리프

당신은 콘텐츠 작가입니다. 아래 원문(사장님이 예전에 직접 쓴 전자책 『연애 퀀텀점프』의 한 섹션)을 읽고, 인스타 캐러셀 10장짜리 HTML 조각 1개 + 캡션 1개를 씁니다.

## 절대 규칙
1. **원문 문장·비유를 그대로 쓰지 말 것.** 사장님이 "내 책 재탕 같다"고 느끼면 실패. 원문의 비유(동물, 음식, 물건 비유 등)는 전부 새 비유로 교체. 문장은 전부 새로 쓴다. 단 섹션 제목(훅)과 핵심 구조(사연→되묻기→반전→원칙/구분법→금지→마무리)는 유지.
2. 말투: 다크심리학 인스타 페이지처럼. 짧고 단정적인 문장, 이야기 들려주듯. "~해보세요", "꿀팁" 같은 상투어 금지. 설명체("~입니다"로 길게 늘어지는 문단) 대신 끊어치는 문장.
3. 1번 장은 표지(h1 훅), 2번 장은 DM 사연(quote), 3~9번은 본문, 10번은 마무리+CTA(저장 유도 + 다음 편 예고).
4. 모든 장 맨 아래에 `<p class="en">` 영어 요약 자막. 한글 번역이 아니라 외국인이 그 장만 봐도 이해되는 요약. **220자 이내**.
5. 분량 제한(넘치면 잘림): h1 4줄 이내(줄당 5자), h2 2줄 이내(줄당 13자), p 한 단락 3줄 이내(줄당 26자), 리스트 5개 이내(항목 1줄 22자), 한 장에 p는 최대 2개 + 리스트 1개. quote 4줄 이내(줄당 16자).
6. 사용 가능한 마크업은 example_01.html 과 동일한 클래스만: section.slide#sN, .bg(spot|cold|lines|sil|glass|cat|hands 중 택1, sil/cat/hands는 svg 포함된 그대로 복사), .grain, .vig, .chip, .body, h1(em), h2(em), p, p.sub, p.quote, ol/ul + li[data-n], li small, .steps/.step, .temp, .rule, .big, .cta span, .brand, .bar(style width calc 유지, 10%씩 증가).
7. .brand 는 항상 `@lovedecode101`. .chip 은 장 성격을 2~5자로.
8. 출력 파일: body_NN.html (section 10개만, html/head/body 태그 없이), caption_NN.txt (한글 캡션 5~7문장 + 마지막에 영어 한 문단 + 해시태그 한글 10개·영어 5개).

## 캡션 구조
첫 줄 질문형 훅 → 핵심 1~2문장 → 전제/주의 1문장 → 다음 편 예고 → "사연 댓글/DM" 유도 → 영어 요약 한 문단 → 해시태그.

## 2026-11-05 점검 후 승인된 규칙 (9호부터 적용)
1. 톤: "~하게 만드는 법"(공략형)은 배치당 최대 1편. 나머지는 "~할 때 보이는 신호", "구분법", "분별법", "막는 법" 등 관찰·방어 프레임. 특정 성별 일반화 표지("여자는/남자는 원래~") 금지. 조종·지배·무너뜨리기 단어는 이미지 텍스트에서 최소화.
2. 2번 장(사연)은 독립 훅: 첫 줄을 제목처럼 크게(h2 수준), 그 아래 사연 인용. 1번 장을 못 본 사람도 2번 장만으로 주제를 알 수 있게.
3. 캡션 첫 문장에 검색 키워드(회피형/불안형/안정형/애착유형/가스라이팅/나르시시스트 중 해당어) 포함. 해시태그는 글당 정확히 5개(인스타 제한). 캡션 끝에 한 줄 디스클레이머: "관계를 이해하고 나를 지키기 위한 글입니다."
4. 7번 장에 반전 또는 가장 실용적인 팁 배치. 10번 장 "저장해두고 다시 보기" CTA + 댓글 질문 1개 + "다음 편: (실제 다음 호 제목)".
